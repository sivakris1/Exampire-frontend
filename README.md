🎓 Exampire (Frontend)
Exampire is a clean and intuitive user interface designed for university students to search, view, and download previous years' academic exam question papers.

🚀 Key Features
Paper Directory: Browse past exams categorized by department, semester, and individual subjects.
Upload Interface: Intuitive upload form allowing users to submit new PDF exam papers to the database.
Modern Dashboard: Responsive navigation menu and layout displaying recently viewed resources and subjects.
Optimized UI: Fast rendering times using React state management and React Router DOM.
🛠️ Tech Stack
Framework: React.js (Create React App)
Styling: CSS3
Routing: React Router DOM
Language: JavaScript (ES6)
⚙️ Local Development Setup
Clone the repository: git clone https://github.com/sivakris1/Exampire-frontend.git cd Exampire-frontend

Install dependencies: npm install

Start the development server: npm start
